# Known limitations and risks

- 导入自动重试目前作用于 WebUI 的「导入全部」入口；CLI `cli.py import` 不含该
  整体重试（CLI 抛错后由用户重新执行，断点续传仍生效）。这是决策 D1 的既定范围。
- 导出文件按时间戳命名，重复导出会累积多组文件（不覆盖旧文件）。
- `.git/info/exclude` 新增了大数据路径排除（qdrant_sampling_map_*.json、
  data_google/、data_xian/、outputs/ 等生成数据），仅影响本地 Git 枚举与 Native
  快照预算，不进入任何提交；与源目录 config 中未提交的 snapshot.exclude 语义一致。
- Windows 下 pytest 输出含 `\r` 且超 4096 字节时，`comet native receipt automated`
  的输出摘要校验会失败；本次使用 `tr -d '\r' | tail -c 2000` 包装并透传 pytest
  退出码规避（证据命令仍真实执行全部测试）。
